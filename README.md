# QubeUtils Homebrew Tap

This is the official Homebrew tap for [QubeUtils](https://github.com/QubeUtils).

## How do I install these formulae?

You can install a formula directly using:

```bash
brew install qubeutils/tap/<formula>
```

Or you can tap the repository first and then install:

```bash
brew tap qubeutils/tap
brew install <formula>
```

## Available Formulae

### `golurk`
Full featured Project Structure Analyzer & LLM Context Builder. ([Homepage](https://github.com/QubeUtils/Golurk))

```bash
brew install qubeutils/tap/golurk
```
